# 人生觉醒测试｜授权码商业版

手机H5规则匹配测评，无需AI接口。包含8位授权码、服务端验证、Supabase数据库、单次激活、同设备续访、报告云端保存、管理员批量发码与禁用。

## 必做部署步骤

1. 创建 Supabase 项目，在 SQL Editor 执行 `supabase.sql`。
2. 复制 `.env.example` 为 `.env.local`，填写 Supabase Project URL、**service_role** 密钥以及三个独立随机秘密（建议用 `openssl rand -hex 32` 生成）。**切勿把 `.env.local` 上传到 GitHub。**
3. Node.js 20+ 下运行 `npm install && npm run dev`，访问首页与 `/admin`。
4. 在 Vercel 导入 GitHub 私人仓库，并配置上述五个环境变量，部署成功后测试真实授权流程。
5. 在 `/admin` 输入 ADMIN_TOKEN，生成授权码并立即导出，向买家发送网址和单独授权码。

## 授权规则

- 每个码仅能激活一次；首次激活时发放签名 HttpOnly cookie，30天有效。相同浏览器可续访并重复查看报告。
- 更换设备或清除 cookie 后**无法凭已激活的授权码恢复**，需商家人工处理；正式销售前应制定售后补发策略。
- 每个码仅保存首次生成的报告，防止多人共享一个码无限生成报告。再次提交返回已保存报告。
- 管理后台目前仅允许禁用未激活码，不提供订单支付集成或已激活码解绑。
- **防刷局限**：没有持久化 IP 限流、验证码和完整审计日志；上线前应配置 Vercel/WAF 限流与监控，管理令牌应妥善保管。
- 使用 Supabase service_role 仅在服务端；数据库开启 RLS，无匿名访问策略。授权码数据库只保存 SHA-256 加盐摘要与末4位，不保存明文。
- 仅为探索性成长自评，不是经过心理测量验证的标准化量表。

## 检查

`npm test` 验证题库/报告结构；`npm run build` 进行 Next.js 生产构建。还需要上线后人工完整测试：无效码、已使用码、断网、跨设备、重复提交、报告恢复与管理后台权限。
